# CrisisMate Demo Flow

## Scenario

A person notices smoke coming from their kitchen.

## Demo

### Step 1

Open CrisisMate.

### Step 2

Enter:

"There is smoke coming from my kitchen."

### Step 3

Click:

HELP ME NOW

### Step 4

The system analyzes the situation.

### Step 5

Display:

- Emergency type
- Risk level
- Immediate actions
- Things to avoid
- Next step

## Expected Flow

User
→ Frontend
→ Backend
→ Gemini
→ Validation
→ Firebase
→ Frontend

## Demo Goal

Show how CrisisMate converts a confusing emergency
description into clear, prioritized next actions.
